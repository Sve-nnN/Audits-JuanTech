## Trust Boundaries

| Boundary | Description |

| `SocialPreviewData` (title/pageUrl derivados del sitio auditado) → `buildFixSnippet` → string HTML → `<code>{snippet}</code>` en pantalla → portapapeles del usuario → `<head>` del sitio del usuario (fuera de nuestro control) | Contenido no confiable interpolado dentro de una plantilla de etiqueta HTML que el usuario luego pega en SU PROPIO sitio |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-32-11 | Tampering | `buildFixSnippet` — un `title`/`pageUrl` con `"`, `<`, `>` o `&` podría romper el atributo `content` del `<meta>` generado o inyectar un tag adicional en el snippet copiado | medium | mitigate | `escapeAttr` aplica escape de atributo HTML (`&`, `"`, `<`, `>`) a todo `value` antes de interpolarlo — el snippet resultante es HTML válido incluso con contenido hostil. |
| T-32-12 | Tampering | `FixSnippet.tsx` — el snippet (texto del sitio auditado, ya HTML-como-texto) se muestra en pantalla | low | mitigate | Se renderiza siempre como `children` de `<code>` (React escapa), nunca vía `dangerouslySetInnerHTML` — el snippet nunca se interpreta como HTML dentro de NUESTRA página, solo se copia como texto. |
| T-32-13 | Repudiation / Information Disclosure | Botón de copiar / descarga — ningún dato sensible (email, token) puede llegar aquí | low | accept | `SocialPreviewData` nunca contiene PII por construcción (mismo contrato que `ReportModel`, ver docblock de `model.ts`); el snippet solo contiene title/URL/valores técnicos ya públicos en el HTML del sitio auditado. |
