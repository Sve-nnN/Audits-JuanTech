**Paquete nuevo:** `packages/fingerprint` (`@auditor/fingerprint`, workspace, puro, dep runtime unica: `cheerio`).

**Tipos publicos (`packages/fingerprint/src/types.ts`, exportados por `src/index.ts`):**
- `Axis` — union `"cms" | "builder" | "cdn" | "hosting" | "jsFramework" | "analytics"`.
- `Confidence` — union `"alto" | "medio" | "bajo" | "no-detectado"`.
- `SignalStrength` — union `"fuerte" | "debil"`.
- `Signal` — `{ id, axis, strength, evidence, unequivocal?: boolean }`.
- `AxisResult` — `{ value: string | null, confidence: Confidence, signals: Signal[] }`.
- `DetectedStack` — `{ cms, builder, cdn, hosting, jsFramework: AxisResult, analytics: AxisResult[] }`.
- `PageFingerprintInput` — `{ url, isHome, html, responseHeaders, cookieNames }` (desacoplado de Prisma).
- `Signature` — `{ id, axis, value, strength, unequivocal?: boolean, test(ctx: AggregatedInput): number }`.
- `AggregatedInput` — forma normalizada que recibe `Signature.test` (headers lowercase agregados, cookieNames union, html elegido, cheerio pre-cargado).

**Funcion publica:** `detectStack(input: { pages: PageFingerprintInput[] }): DetectedStack` (Plan 25-04).

**Registry de signatures:** `registry: Record<Axis, Signature[]>` con modulos por eje `signatures/{cms,builder,cdn,hosting,jsFramework,analytics}.ts` (Plan 25-03).

**Columnas Prisma nuevas (modelo `Page`, Plan 25-02):**
- `Page.responseHeaders Json?` — headers HTTP curados.
- `Page.cookieNames String[]` — nombres de cookie (nunca valores).

**Helpers de captura en crawler (Plan 25-02):** `packages/crawler/src/captureHeaders.ts` exporta `CURATED_HEADER_KEYS`, `curateHeaders()`, `parseCookieNames()`.
