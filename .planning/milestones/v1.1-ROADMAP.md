# Milestone v1.1: Overhaul de UI/UX y marca

**Status:** ✅ SHIPPED 2026-07-06
**Phases:** 8-10
**Total Plans:** 19 (5 + 6 + 8)

## Overview

Una vez validado el pipeline funcional en v1.0, el overhaul de UI se construyó de fundamentos hacia afuera: primero las fuentes de marca y el design system (tokens, tema claro/oscuro, layout base) porque todo lo demás depende de esas variables y decisiones visuales; luego la librería de componentes reutilizables (score gauge, cards, badges, tabla de issues, acordeones, formularios, estados vacíos/skeletons) que consume esos tokens; y por último las pantallas completas, donde se ensamblan los componentes, se aplica el copy humanizado, el motion sutil y se valida accesibilidad/responsive de punta a punta. No se tocó lógica de crawl/checks/scoring/email — v1.1 fue estrictamente UI-only sobre la superficie de v1.0.

## Milestone Summary

**Decimal Phases:** Ninguna (sin inserciones urgentes durante v1.1).

**Key Decisions:**

- Array queda expuesta como token (`--font-array`) pero NO se aplica a headings — los títulos van en Khand por decisión de marca de Juan (UI-FEEDBACK.md).
- Componentes tokens-only, cero hex crudo, para garantizar coherencia dark/light y facilitar el theming.
- Acordeones sobre `details/summary` nativos (accesibilidad de teclado gratis).
- No se construyó ruta `/styleguide`; la validación visual de componentes se difirió a la Fase 10 (pantallas reales).
- v1.1 estrictamente UI-only: cero cambios en crawl/checks/PSI/scoring/email.

**Issues Resolved:**

- Home flotaba con vacío vertical enorme (centrado a 100vh) → hero rehecho con densidad correcta.
- Contraste bajo en descripción/footnote del home → subido a AA.
- Copy con voceo ("Ingresá", "podés") → reescrito a español neutro sin voceo.
- Skeleton (COMP-08) estaba construido pero sin consumidor → cableado en `loading.tsx` de reporte/historial/páginas (commit 58eed79).
- Code review Fase 10: 1 BLOCKER (loop de reload en auditorías fallidas) + warnings (main anidado rompía skip-link, badge Crítico falso, tick sin try/catch) corregidos.

**Issues Deferred:**

- `Input` sin `forwardRef` (TS2322 en HomeClient) surgido de agentes concurrentes — resuelto durante el cierre de fase; sin deuda abierta al cierre del milestone.

**Technical Debt Incurred:**

- Ninguna bloqueante. Export PDF / branding compartible y gráficos custom por categoría siguen fuera de alcance (v2 / post-v1.1).
