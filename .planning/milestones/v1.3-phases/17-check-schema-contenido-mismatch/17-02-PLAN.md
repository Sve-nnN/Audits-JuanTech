<objective>
Reorder the worker pipeline so the v1.2 render sample (`runRenderSample`) runs before the check battery (`runAllChecks`), and thread its per-page SSR/CSR/undetermined verdict into `runAllChecks` as `renderVerdictByPageId`, so the SD-06 check built in 17-01 can suppress false positives on pages already confirmed CSR.

Purpose: closes SCHEMA-07's cross-check requirement — a page correctly identified as CSR by `@auditor/render` must not also get flagged by SD-06 for "missing" content that's simply not present in the raw HTML by design.
Output: `RenderIssueDraft` exposes an explicit `verdict` field; the worker builds `renderVerdictByPageId` from the (already best-effort, already-existing) render pass and passes it through to `runAllChecks`, with the render pass moved earlier in the pipeline.
</objective>
