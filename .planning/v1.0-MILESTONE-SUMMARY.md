## Bugs reales encontrados y arreglados durante verificación (6)

1. **4xx/5xx sin statusCode** (Fase 2): CheerioCrawler trataba 404/500 como error → `ignoreHttpErrorStatusCodes` para registrarlos (habilita TECH-03).
2. **Huérfanas falsos positivos** (Fase 3): comparaba sitemap completo vs crawl parcial → 66 FP → 3.
3. **BullMQ "Lock mismatch"** (Fase 3): checks CPU-pesados bloqueaban renovación de lock → `lockDuration > JOB_TIMEOUT`.
4. **@id cross-page FP** (Fase 4): resolución per-page → 28 FP → resolución site-wide → 0.
5. **PSI env/key** (Fase 5): confirmado que el worker carga PSI_API_KEY vía Prisma.
6. **Scoring size-dependent** (Fase 6): penalización absoluta tanqueaba sitios grandes (onpage=0) → pass-rate ponderado → overall 64→91.
