# Phase 9 — UI Design Contract

> Visual and interaction contract for the reusable component library built ON TOP of the Phase 8 tokens/fonts. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This phase specifies the reusable primitives only (COMP-01..08): score gauge, category cards, badges, responsive issues table, category-detail accordion, buttons/inputs/forms with states, empty/error states, loading skeletons. Each component ships with static states (no live motion). Full screen assembly, humanized final copy, live motion, and end-to-end responsive/a11y are Phase 10. Every value below references the Phase 8 contract (`apps/web/app/tokens.css`, `08-UI-SPEC.md`) as source of truth — no new tokens are introduced.

## Component Architecture (locked, 09-CONTEXT.md)

- **Location:** `apps/web/app/components/ui/` (alongside the Phase 8 shell). One folder or file pair per component, not a separate package.
- **Styling:** one CSS Module per component, camelCase single-word class names (`gauge`, `card`, `badge`), imports relative within `app/`. Modules reference **semantic tokens only** (`var(--surface)`), never raw hex or primitive ramps.
- **API:** typed `"use client"` components, named exports, variants driven by props (`variant` / `size` / `state`). Boolean state flags (`disabled`, `error`, `loading`) map to CSS Module classes.
- **Icons:** `lucide-react` named imports only (e.g. `import { AlertTriangle } from "lucide-react"`). Icons inherit `currentColor`; size via `size` prop mapped to px below.
- **Copy:** neutral-Spanish placeholders, NO voceo, no em/en dashes. Final humanized copy lands in Phase 10 (COPY-01/02). Every placeholder string here is already voceo-free.
- **Motion:** structural + static states only. No live count-up/reveal/transition in this phase. Any `transition` declared here is a ≤150ms micro-interaction (hover/focus color) and MUST be wrapped in `@media (prefers-reduced-motion: reduce) { transition: none }`.

## Color

Inherited from Phase 8 semantic tokens (dark-first, light override under `[data-theme="light"]`). Contrast targets: text ≥ 4.5:1, large numerals ≥ 3:1 (AA). Per UI-FEEDBACK.md, secondary/help text MUST use `--text-secondary` (not `--text-muted`) wherever it carries meaning, to hold AA — `--text-muted` is reserved for genuinely de-emphasized/disabled/placeholder content.

| Role | Token | Usage in this phase |
|------|-------|---------------------|
| Dominant (60%) | `--bg` | Page canvas behind components; table header row fill |
| Secondary (30%) | `--surface` | Cards, table body, accordion panels, empty/error containers, inputs base |
| Surface raised | `--surface-raised` | Input fill, elevated/popover surfaces |
| Surface hover | `--surface-hover` | Table row hover, card hover, ghost-button hover, diff "persistent" badge fill |
| Border | `--border` | Card/table/accordion borders, dividers |
| Border strong | `--border-strong` | Input default border, focus container |
| Text primary | `--text` | Card titles, issue titles, primary readouts |
| Text secondary | `--text-secondary` | Card labels, help text, table `<th>`, meta captions (AA-safe) |
| Text muted | `--text-muted` | Placeholders, disabled text, "sin datos" only |
| Accent (10%) | `--accent` / `--accent-hover` / `--accent-foreground` | Primary button fill only |
| Accent text | `--accent-text` | Inline links, diff "new" badge foreground, clickable table URL |
| Focus ring | `--ring` (+ `--shadow-focus`) | `focus-visible` outline on every focusable component |
| Critical | `--critical` | Severity "crítico" badge, error state icon/border, input error border, score-state critical |
| Warning | `--warning` | Severity "advertencia" badge, score-state needs_improvement |
| Success | `--success` | Severity "correcto"/OK badge, diff "resolved" badge, score-state good |

Accent reserved for (unchanged from Phase 8, never "all interactive elements"):
1. Primary CTA / primary button fill (`--accent` bg + `--accent-foreground` text).
2. `focus-visible` ring on all focusable elements (`--ring`).
3. Inline text links and clickable table URL (`--accent-text`, theme-aware).
4. (Header active nav + brand glyph — shell only, Phase 8.)

**Severity is a separate axis** and is never substituted by the brand accent. **Score-state coherence (DS-02):** `good → --success`, `needs_improvement → --warning`, `critical → --critical` — the same three tokens back both the severity badges and the score-state colors.

**Soft severity fills (carry over from report.module.css, keep):** derive tinted backgrounds via `color-mix(in srgb, var(--<token>) 12%, transparent)` so badges stay legible in both themes with zero hardcoded hex. Component-local custom props:
`--sev-good-bg`, `--sev-warn-bg`, `--sev-critical-bg`, `--sev-info-bg` (info = `--accent-text` at 12%).

### COMP-01 — ScoreGauge

Circular SVG score indicator (overall or per-category). Static now; structure ready to animate in Phase 10.

**API**
```ts
interface ScoreGaugeProps {
  value: number | null;      // 0–100; null → "sin datos" state
  max?: number;              // default 100
  status: "good" | "needs_improvement" | "critical" | null;
  size?: "md" | "lg";        // md=96px (category), lg=132px (overall hero). default "lg"
  label?: string;            // optional caption under the number, Geist Sans 14
  "aria-label"?: string;     // e.g. "Score general 86 de 100, estado bueno"
}
```

**Structure:** `<svg>` with two concentric `<circle>` paths on a shared center:
- Track circle: `stroke: var(--border)`, `stroke-width: 8` (lg) / 6 (md).
- Progress arc: `stroke: currentColor`, `stroke-width` same, `stroke-linecap: round`, `stroke-dasharray = circumference`, `stroke-dashoffset = circumference * (1 - value/max)`. Rotate `-90deg` so it starts at 12 o'clock.
- `currentColor` set by a status class on the SVG wrapper: `.good{color:var(--success)}`, `.needs_improvement{color:var(--warning)}`, `.critical{color:var(--critical)}`, `.unknown{color:var(--text-muted)}`.
- Centered number: Geist Mono, `--font-size-5xl` (lg) / `--font-size-2xl` (md), weight 700, `font-feature-settings:"tnum" 1`, `line-height:1`, color `var(--text)`.
- "/ 100" sub-label: Geist Mono, `--font-size-sm`, `var(--text-muted)`, `--space-1` above.

**Sizing:** lg 132×132, md 96×96. `flex-shrink:0`.

**States**
- default: arc filled to value, colored by status.
- null value: render full track only (no arc), number replaced by em dash `—` in `--text-muted`, `aria-label` = "Score sin datos".
- Motion-ready (not live): `stroke-dashoffset` is a CSS custom prop `--gauge-offset` so Phase 10 can animate it; ship at final value now. NO `transition` on the offset in this phase.

**A11y:** `role="img"` on the SVG with a required `aria-label` (number + status in words). Decorative track/arc `aria-hidden`. Not focusable (presentational). Color is never the sole signal — the numeric value and the status word (via aria-label, and the adjacent status caption/badge) carry meaning.

### COMP-02 — CategoryCard

Compact card: category label + score + status, consistent across the 5 categories.

**API**
```ts
interface CategoryCardProps {
  label: string;                       // e.g. "SEO Técnico"
  score: number | null;
  status: "good" | "needs_improvement" | "critical" | null;
  statusLabel?: string;                // e.g. "Bueno" | "Necesita mejora" | "Crítico" | "sin datos"
  href?: string;                       // optional → whole card becomes a link
}
```

**Layout:** `background:var(--surface)`, `border:1px solid var(--border)`, `border-radius:var(--radius-md)` (10px), `padding:var(--space-4)` (mobile) → `var(--space-5)` (≥640px). Vertical stack, `gap:var(--space-2)`.
- Label: Geist Sans 14 (`--font-size-sm`), `var(--text-secondary)`, weight 400.
- Score: Geist Mono `--font-size-2xl` (24px), weight 700, tnum, colored by status class (same map as gauge); null → `—` in `--text-muted`.
- Status caption: Geist Sans `--font-size-xs` (12px), weight 600, colored by status class; null → "sin datos" in `--text-muted`.

Grid host: `repeat(auto-fit, minmax(170px, 1fr))`, `gap:var(--space-6)` (24px) — one column on mobile.

**States**
- default: as above.
- hover (only when `href` present): `background:var(--surface-hover)`, `border-color:var(--border-strong)`, `transition:background .15s ease, border-color .15s ease` (reduced-motion → none).
- focus-visible (link card): `outline:2px solid var(--ring); outline-offset:2px`.
- null/no-data: muted score + "sin datos", no colored accent.

**A11y:** if `href`, render as a single `<a>` wrapping content (one tab stop, not nested interactives). Status conveyed by both color and the status word. Card is not a heading; the label is a `<p>`.

### COMP-03 — Badge (SeverityBadge + DiffBadge)

Reusable pill for severity and diff status. One `Badge` primitive with a `variant` prop; two thin typed wrappers for ergonomics.

**API**
```ts
type BadgeVariant =
  | "critical" | "warning" | "ok"        // severity axis
  | "new" | "persistent" | "resolved"    // diff axis
  | "info" | "neutral";
interface BadgeProps {
  variant: BadgeVariant;
  children: React.ReactNode;             // label text, already localized
  icon?: LucideIcon;                     // optional leading icon, 14px
}
// Wrappers:
// SeverityBadge: severity "critical"|"warning"|"ok" → localized label
// DiffBadge: diff "new"|"persistent"|"resolved" → localized label
```

**Base:** `display:inline-flex; align-items:center; gap:var(--space-1); padding:var(--space-1) var(--space-2); border-radius:var(--radius-full); font-family:var(--font-geist-sans); font-size:var(--font-size-xs)` (12px); `font-weight:600; line-height:1.4; white-space:nowrap`.

**Variant → tokens (foreground / soft background):**
| variant | foreground | background |
|---------|------------|------------|
| critical | `--critical` | `--sev-critical-bg` (critical @12%) |
| warning | `--warning` | `--sev-warn-bg` (warning @12%) |
| ok | `--success` | `--sev-good-bg` (success @12%) |
| new | `--accent-text` | `--sev-info-bg` (accent-text @12%) |
| persistent | `--text-secondary` | `--surface-hover` |
| resolved | `--success` | `--sev-good-bg` |
| info | `--accent-text` | `--sev-info-bg` |
| neutral | `--text-secondary` | `--surface-hover` |

Optional icon (lucide) at 14px inherits `currentColor`. Suggested defaults: critical→`AlertOctagon`, warning→`AlertTriangle`, ok→`CheckCircle2`, new→`Sparkle`, persistent→`Circle`, resolved→`CheckCircle2`.

**Copy placeholders (voceo-free):** severity → `Crítico` / `Advertencia` / `Correcto`; diff → `Nuevo` / `Persistente` / `Resuelto`.

**A11y:** decorative pill; icon is `aria-hidden` (text label carries meaning). Color never sole signal — the word is always present. Static, not focusable.

### COMP-04 — IssuesTable

Responsive priority-issues table. Locked decision: **horizontal scroll with a sticky, clickable URL column** — does NOT collapse to cards.

**API**
```ts
interface IssuesTableColumn {
  key: string; header: string;
  align?: "left" | "right";
  mono?: boolean;                        // Geist Mono cell (measured values)
  sticky?: boolean;                      // pins column (the URL column)
}
interface IssuesTableProps {
  columns: IssuesTableColumn[];
  rows: React.ReactNode[][] | IssueRow[]; // renderable cells
  caption?: string;                       // e.g. "Issues prioritarios"
  note?: string;                          // e.g. "Mostrando 60 de 142…"
  emptyLabel?: string;                    // when rows empty → renders EmptyState
}
```
Reference columns (from current report): Categoría · Issue · Página (sticky, clickable) · Severidad · Valor medido (mono) · Estado.

**Container:** wrapper `overflow-x:auto; -webkit-overflow-scrolling:touch`, with `border:1px solid var(--border); border-radius:var(--radius-md); background:var(--surface)`. Inner `<table>` `border-collapse:collapse; width:100%; min-width:640px` (forces horizontal scroll below that instead of squashing).

- `<th>`: Geist Sans `--font-size-xs` (12px), weight 600, uppercase, `letter-spacing:.03em`, `var(--text-secondary)`, `background:var(--bg)`, `padding:var(--space-3) var(--space-4)`, `border-bottom:1px solid var(--border)`, `text-align:left`, sticky top when the table scrolls vertically inside a fixed region (`position:sticky; top:0`).
- `<td>`: Geist Sans `--font-size-sm` (14px), `var(--text)`, `padding:var(--space-3) var(--space-4)`, `border-bottom:1px solid var(--border)`, `vertical-align:top`. Last row: no bottom border.
- Mono columns (`mono`): Geist Mono, tnum, `--text` (or `--text-secondary` for de-emphasis).
- **Sticky URL column:** `position:sticky; left:0; z-index:1; background:var(--surface)` (matches row bg so content underneath doesn't show through); on hover row, background follows `--surface-hover`. A subtle right divider `box-shadow: 1px 0 0 var(--border)` marks the seam. Cell contents: clickable `<a>` in `--accent-text` (`shortUrl(...)` display, full URL in `title`), external links `target="_blank" rel="noreferrer"`. Non-URL scopes render as plain `--text-secondary` text.
- Row hover: `background:var(--surface-hover)` (reduced-motion safe — instant).
- Note line: Geist Sans `--font-size-sm`, `var(--text-secondary)`, `margin-top:var(--space-2)`.

**Empty state:** when `rows` empty, render COMP-07 EmptyState inside the section (icon `CheckCircle2`, `--success`) with `emptyLabel` (placeholder: `Sin issues críticos ni de advertencia.`).

**A11y:** real `<table>` with `<caption>` (visually the section title or `sr-only`), `<thead>`/`<th scope="col">`. Clickable URL is a real `<a>` with accessible name = full URL (via `title`/`aria-label`). Horizontal scroll region is keyboard-reachable (`tabindex="0"` + `role="region"` + `aria-label` on the scroll wrapper so keyboard users can scroll it). No content is hidden/truncated without a title tooltip.

### COMP-05 — CategoryAccordion

Per-category detail disclosure (Problemas vs Correcto), keyboard-accessible.

**API**
```ts
interface AccordionProps {
  title: string;                         // category label
  count?: string;                        // e.g. "3 problema(s) · 12 correcto(s)"
```

- expanded: `[open]` shows body, chevron rotated.
- summary hover: `background:var(--surface-hover)`.

**A11y:** native `<summary>` is a button in the a11y tree — Enter/Space toggles, expanded state exposed automatically. Focus ring visible (lime). Clickable URLs inside rows are real `<a>`. No color-only meaning (badges carry words).

### COMP-06 — Button, Input, Field

#### Button
```ts
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: "primary" | "secondary" | "ghost" | "destructive"; // default "primary"
  size?: "sm" | "md" | "lg";            // default "md"
  loading?: boolean;                     // spinner + disabled
  iconLeft?: LucideIcon; iconRight?: LucideIcon;
}
```
**Base:** `display:inline-flex; align-items:center; justify-content:center; gap:var(--space-2); font-family:var(--font-geist-sans); font-weight:600; border-radius:var(--radius-md); border:1px solid transparent; cursor:pointer; transition:background .15s ease, border-color .15s ease, color .15s ease` (reduced-motion → none).

**Sizes:** sm → `font-size:var(--font-size-sm)` (14), `padding:var(--space-2) var(--space-3)`, min-height 36px. md → 14px, `padding:var(--space-3) var(--space-4)`, min-height 44px (touch). lg → `--font-size-base` (16), `padding:var(--space-3) var(--space-6)`, min-height 48px.

**Variants (default → hover → active):**
| variant | bg | text | border | hover |
|---------|-----|------|--------|-------|
| primary | `--accent` | `--accent-foreground` | transparent | bg `--accent-hover` |
| secondary | `--surface-raised` | `--text` | `--border-strong` | bg `--surface-hover` |
| ghost | transparent | `--text` | transparent | bg `--surface-hover` |
| destructive | transparent | `--critical` | `--critical` | bg `--sev-critical-bg` |

**States**
- hover: per table (instant under reduced-motion).
- focus-visible: `outline:2px solid var(--ring); outline-offset:2px` + `box-shadow:var(--shadow-focus)`.
- disabled: `opacity:.5; cursor:not-allowed; pointer-events:none` — no hover change.
- loading: render lucide `Loader2` 16px with a spin animation **guarded by reduced-motion** (static icon when reduced), `aria-busy="true"`, button disabled, label stays for width stability.
- Icons: 16px (sm/md), 18px (lg), inherit `currentColor`.

**A11y:** real `<button type>`. Icon-only buttons require `aria-label` and 44×44 min. Loading sets `aria-busy`. Disabled uses the `disabled` attribute (not just visual). Focus ring always visible.

#### Input
```ts
interface InputProps extends React.InputHTMLAttributes<HTMLInputElement> {
  invalid?: boolean;       // error styling; pair with aria-invalid
  inputSize?: "md" | "lg"; // default "md"
}
```
**Base:** `background:var(--surface-raised); color:var(--text); border:1px solid var(--border-strong); border-radius:var(--radius-sm)` (6px); `padding:var(--space-3) var(--space-4)`; `font-family:var(--font-geist-sans); font-size:var(--font-size-base)` (16px — prevents iOS zoom); `line-height:var(--lh-body); width:100%; min-height:44px`. Placeholder: `var(--text-muted)`. URL/email inputs may opt into Geist Mono via a `mono` flag.

**States**
- default: as base.
- hover: `border-color:var(--text-muted)`.
- focus-visible: `border-color:var(--ring); outline:2px solid var(--ring); outline-offset:1px; box-shadow:var(--shadow-focus)`.
- disabled: `background:var(--surface); color:var(--text-muted); cursor:not-allowed; opacity:.6`.
- error (`invalid`): `border-color:var(--critical)`; on focus keep `--critical` border but ring stays `--ring` (or `--critical` glow) — pair with `aria-invalid="true"` and a linked error message.

#### Field (form wrapper)
```ts
interface FieldProps {
  label: string; htmlFor: string;
  hint?: string; error?: string;
  required?: boolean; children: React.ReactNode; // the Input/control
}
```
Vertical stack `gap:var(--space-2)`.
- Label: Geist Sans 14/600, `var(--text)`; required marker `*` in `--critical` with `aria-hidden` + visually-hidden "obligatorio".
- Hint: Geist Sans 14/400, `var(--text-secondary)`, linked via `aria-describedby`.
- Error: Geist Sans 14/400, `var(--critical)`, with lucide `AlertCircle` 14px, `id` linked via `aria-describedby` and control gets `aria-invalid="true"`. Error replaces hint when present.

**A11y:** every control has an associated `<label htmlFor>`. Error text is programmatically linked (`aria-describedby`) and announced (add `role="alert"` on the error node). Never rely on red border alone — the error message text is mandatory. Focus ring lime and visible.

**Copy placeholders (voceo-free):** submit CTA `Auditar mi sitio`; field label `Correo` / `URL del sitio`; error example `Ingresa un correo valido.` / `Ingresa una URL valida.`; hint example `Te enviamos un enlace de verificacion.`

### COMP-07 — EmptyState / ErrorState

Icon slot + title + description + optional action (locked shape).

**API**
```ts
interface StateMessageProps {
  variant?: "empty" | "error";          // default "empty"
  icon?: LucideIcon;                     // default: empty→Inbox, error→AlertTriangle
  title: string;
  description?: string;
  action?: { label: string; onClick?: () => void; href?: string };
}
```
**Layout:** centered column, `background:var(--surface); border:1px dashed var(--border); border-radius:var(--radius-md); padding:var(--space-10) var(--space-8); text-align:center; gap:var(--space-3)`; `max-width: 52ch; margin-inline:auto`.
- Icon: 32px, in a `--radius-full` chip `56×56`. empty → `var(--text-muted)`; error → `var(--critical)` on `--sev-critical-bg` chip.
- Title: Khand h4 role (20px/500), `var(--text)`.
- Description: Geist Sans 16 (`--font-size-base`), `var(--text-secondary)` (AA), `line-height:1.5`.

### COMP-08 — Skeleton

Loading placeholder with CSS shimmer that respects `prefers-reduced-motion`.

**API**
```ts
interface SkeletonProps {
  variant?: "text" | "block" | "circle" | "gauge" | "card" | "row";
  width?: string | number;   // default 100%
  height?: string | number;  // default per variant
  lines?: number;            // for "text" multi-line
  "aria-hidden"?: true;      // always true — decorative
}
```
**Base:** `background:var(--surface-hover); border-radius:var(--radius-sm); position:relative; overflow:hidden`. Shimmer via a `::after` gradient sweep `background:linear-gradient(90deg, transparent, color-mix(in srgb, var(--text) 6%, transparent), transparent); animation:shimmer 1.4s ease-in-out infinite`.

**Variants:** text → height 14px, `border-radius:var(--radius-sm)`, last line 60% width when `lines>1`, line gap `var(--space-2)`. block → default height 20px. circle → `border-radius:var(--radius-full)`, equal width/height. gauge → 132×132 circle matching ScoreGauge lg footprint. card → `var(--surface)` outer with `border:1px solid var(--border); border-radius:var(--radius-md); padding:var(--space-4)` wrapping a title-line + score-block skeleton. row → table-row height block.

**Reduced motion (mandatory):**
```css
@media (prefers-reduced-motion: reduce) {
  .skeleton::after { animation: none; }
  .skeleton { /* optional low static pulse via opacity, or none */ }
}
```
Under reduced motion the shimmer is removed; the muted block remains as a static placeholder.

**A11y:** always `aria-hidden="true"` (purely decorative). The live region announcing "cargando" is the responsibility of the consuming screen (Phase 10), which pairs a `role="status"` `sr-only` "Cargando…" with the visual skeletons — skeletons themselves add no semantics.

## Cross-Cutting Accessibility Contract

- **Focus ring:** every focusable component uses `outline:2px solid var(--ring); outline-offset:2px` (inset `-2px` where clipping by `overflow:hidden`, e.g. accordion summary), plus `--shadow-focus` glow where a solid outline alone is subtle. Never `outline:none` without a replacement.
- **Color is never the only signal:** severity/diff/score-state always pair color with a text label or numeric value.
- **Touch targets:** interactive controls ≥ 44×44px (buttons md+, icon buttons, accordion summary hit area).
- **Contrast:** meaningful text ≥ 4.5:1 (use `--text` / `--text-secondary`, not `--text-muted`, for content that must be read — direct fix for the UI-FEEDBACK.md low-contrast note); large numerals ≥ 3:1. Holds in both themes.
- **Keyboard:** accordions (native `<details>`), buttons/links, table scroll region (`tabindex=0` + `role=region`), and form controls are all keyboard-operable; no keyboard traps.
- **Motion:** any transition/animation guarded by `@media (prefers-reduced-motion: reduce)`. No live count-up/reveal in this phase (Phase 10 owns live motion and must keep the same guard).
- **Semantics:** native elements first — `<button>`, `<a>`, `<table>`, `<details>`, `<label>`. ARIA only to fill gaps (`aria-label` on icon-only/image, `aria-invalid`/`aria-describedby` on fields, `role="status"`/`"alert"` on error/loading regions).
