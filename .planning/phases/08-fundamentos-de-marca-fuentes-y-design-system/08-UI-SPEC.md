# Phase 8 — UI Design Contract

> Visual and interaction contract for the brand foundation: fonts, design tokens, light/dark theming, and base layout primitives. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** This phase specifies ONLY tokens, fonts, theming, and the base layout shell (container, grid, header, footer). Individual components (score gauge, cards, badges, issues table, forms) are Phase 9. Full screens, copy, motion, and end-to-end a11y are Phase 10. Everything below is the source of truth those phases consume.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (CSS Modules + `globals.css` + `tokens.css`; no Tailwind, no shadcn — locked in CONTEXT.md) |
| Preset | not applicable |
| Component library | none (hand-built primitives; no Radix/Base UI in this phase) |
| Theming library | `next-themes` — `attribute="data-theme"` on `<html>`, `localStorage` persistence + `prefers-color-scheme` initial, `suppressHydrationWarning`, no FOUC |
| Icon library | deferred to Phase 9 (recommendation: `lucide-react` — SVG, tree-shakeable, stroke-based fits the technical/terminal aesthetic) |
| Fonts | Array (display, `next/font/local` self-hosted woff2 → `--font-array`) · Khand (headings/UI, `next/font/google` 400/500/600/700 → `--font-khand`) · Geist Sans (body → `--font-geist-sans`) · Geist Mono (code/metrics → `--font-geist-mono`), both via `geist` npm package. `font-display: swap` on all. |

**Registry safety gate:** not applicable — no shadcn, no third-party component registries in this phase.

## Token Architecture

- All tokens live as CSS custom properties in `apps/web/app/tokens.css`, imported at the top of `globals.css`.
- Primitive tokens (raw scales: color ramps, spacing, radii) are defined once on `:root` and are theme-agnostic.
- Semantic tokens (`--bg`, `--surface`, `--text`, `--accent`, `--border`, etc.) are defined on `:root` (dark = default, dark-first) and overridden under `[data-theme="light"]`.
- Component CSS Modules MUST reference semantic tokens only (`var(--surface)`), never raw hex or primitive ramp tokens directly. No hardcoded colors anywhere after this phase.

## Spacing Scale

Base unit 4px. All values are multiples of 4.

| Token | Value | Usage |
|-------|-------|-------|
| `--space-0` | 0 | Reset |
| `--space-1` | 4px | Icon gaps, inline padding, hairline offsets |
| `--space-2` | 8px | Compact element spacing, chip padding |
| `--space-3` | 12px | Input padding, tight stacks |
| `--space-4` | 16px | Default element spacing, card padding (mobile) |
| `--space-5` | 20px | Card padding (desktop) |
| `--space-6` | 24px | Section padding, grid gap |
| `--space-8` | 32px | Layout gaps, header inline padding (desktop) |
| `--space-10` | 40px | Sub-section breaks |
| `--space-12` | 48px | Major section breaks, footer block padding |
| `--space-16` | 64px | Page-level vertical rhythm |
| `--space-20` | 80px | Hero vertical padding (desktop) |
| `--space-24` | 96px | Landing section separation (desktop) |

Exceptions: minimum interactive touch target is 44×44px (WCAG 2.5.5) even when visual padding is smaller — applies to the theme toggle and any icon-only control in the shell.

## Typography

Root font size 16px (`1rem = 16px`). Four typefaces, mapped by role. Running text uses two weights max (400 regular + 600 semibold); condensed Khand headings may also use 500/700.

| Token | Size | Line height token | Line height |
|-------|------|-------------------|-------------|
| `--font-size-xs` | 12px | `--lh-body` | 1.5 |
| `--font-size-sm` | 14px | `--lh-body` | 1.5 |
| `--font-size-base` | 16px | `--lh-body` | 1.5 |
| `--font-size-lg` | 18px | `--lh-snug` | 1.35 |
| `--font-size-xl` | 20px | `--lh-heading` | 1.2 |
| `--font-size-2xl` | 24px | `--lh-heading` | 1.2 |
| `--font-size-3xl` | 30px | `--lh-heading` | 1.2 |
| `--font-size-4xl` | 36px | `--lh-tight` | 1.1 |
| `--font-size-5xl` | 48px | `--lh-tight` | 1.1 |
| `--font-size-6xl` | 60px | `--lh-tight` | 1.05 |

Line-height tokens: `--lh-tight: 1.1` · `--lh-heading: 1.2` · `--lh-snug: 1.35` · `--lh-body: 1.5` · `--lh-relaxed: 1.65`.
Weight tokens: `--weight-regular: 400` · `--weight-medium: 500` · `--weight-semibold: 600` · `--weight-bold: 700`.

### Role mapping (semantic tokens → template roles)

| Role | Family (token) | Size | Weight | Line Height | Notes |
|------|----------------|------|--------|-------------|-------|
| Display | Array (`--font-array`) | 60px (`--font-size-6xl`) | 400 | 1.05 | Hero headline / big brand numbers only. Letter-spacing `-0.02em`. Single weight. |
| Display (secondary) | Array (`--font-array`) | 48px (`--font-size-5xl`) | 400 | 1.1 | Section hero on marketing surfaces. |
| Heading (h1) | Khand (`--font-khand`) | 36px (`--font-size-4xl`) | 600 | 1.1 | Condensed; letter-spacing `0`. |
| Heading (h2) | Khand (`--font-khand`) | 30px (`--font-size-3xl`) | 600 | 1.2 | |
| Heading (h3) | Khand (`--font-khand`) | 24px (`--font-size-2xl`) | 500 | 1.2 | |
| Heading (h4) / UI title | Khand (`--font-khand`) | 20px (`--font-size-xl`) | 500 | 1.2 | Card titles, nav labels. |
| Body | Geist Sans (`--font-geist-sans`) | 16px (`--font-size-base`) | 400 | 1.5 | Default paragraph text. |
| Body small | Geist Sans (`--font-geist-sans`) | 14px (`--font-size-sm`) | 400 | 1.5 | Secondary/help text. |
| Label / emphasis | Geist Sans (`--font-geist-sans`) | 14px (`--font-size-sm`) | 600 | 1.5 | Form labels, button text, emphasis. |
| Code / metrics | Geist Mono (`--font-geist-mono`) | 14px (`--font-size-sm`) | 400 | 1.5 | Scores, URLs, measured values, code. `font-feature-settings: "tnum" 1` (tabular numerals). |

**Fallback stacks (`font-display: swap`):**
- Array → `var(--font-array), "Khand", system-ui, sans-serif`
- Khand → `var(--font-khand), "Arial Narrow", system-ui, sans-serif`
- Geist Sans → `var(--font-geist-sans), system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`
- Geist Mono → `var(--font-geist-mono), ui-monospace, "SFMono-Regular", Menlo, monospace`

## Color

Dark-first. All semantic tokens defined for both themes below. Contrast targets: body/label text ≥ 4.5:1, large headings ≥ 3:1 (WCAG AA).

### Primitive ramps (theme-agnostic, `:root`)

Slate neutrals: `--slate-50 #f8fafc` · `--slate-100 #f1f5f9` · `--slate-200 #e2e8f0` · `--slate-300 #cbd5e1` · `--slate-400 #94a3b8` · `--slate-500 #64748b` · `--slate-600 #475569` · `--slate-700 #334155` · `--slate-800 #1e293b` · `--slate-900 #0f172a` · `--slate-950 #020617`.

Canvas (dark-first extra-dark): `--ink-900 #0a0b0f` · `--ink-800 #11131a` · `--ink-700 #161922` · `--ink-600 #1c1f2a`.

Brand lime: `--lime-300 #d4f97a` · `--lime-400 #c3f53c` (brand accent) · `--lime-500 #a3e635` · `--lime-600 #84cc16` · `--lime-700 #4d7c0f` (accessible lime text on light).

Severity ramps (each has a dark-theme and light-theme accessible shade):
- Critical/red: `--red-400 #f87171` · `--red-500 #ef4444` · `--red-600 #dc2626`
- Warning/amber: `--amber-400 #fbbf24` · `--amber-500 #f59e0b` · `--amber-600 #d97706`
- OK/green: `--green-400 #4ade80` · `--green-500 #22c55e` · `--green-600 #16a34a`

Coherent inversion of the dark-first palette. Severity and accent shift to darker shades to hold AA on light surfaces.

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `--bg` | `#f8fafc` (`--slate-50`) | App canvas |
| Surface (30%) | `--surface` | `#ffffff` | Cards, panels, header, footer |
| Surface raised | `--surface-raised` | `#ffffff` | Popovers, inputs (with border) |
| Surface hover | `--surface-hover` | `#f1f5f9` (`--slate-100`) | Row/card hover |
| Border | `--border` | `#e2e8f0` (`--slate-200`) | Default dividers |
| Border strong | `--border-strong` | `#cbd5e1` (`--slate-300`) | Input borders |
| Text primary | `--text` | `#0f172a` (`--slate-900`) | Headings, body |
| Text secondary | `--text-secondary` | `#475569` (`--slate-600`) | Help text |
| Text muted | `--text-muted` | `#64748b` (`--slate-500`) | Disabled, placeholders |
| Accent (10%) | `--accent` | `#c3f53c` (`--lime-400`) | Fills only; text on it stays `--ink-900` |
| Accent hover | `--accent-hover` | `#a3e635` (`--lime-500`) | Accent fill hover |
| On-accent text | `--accent-foreground` | `#0a0b0f` (`--ink-900`) | Text/icon on accent fill |
| Accent link text | `--accent-text` | `#4d7c0f` (`--lime-700`) | Inline links on light (AA ≈ 4.8:1; raw lime fails on white) |
| Critical | `--critical` | `#dc2626` (`--red-600`) | Severity/destructive |
| Warning | `--warning` | `#d97706` (`--amber-600`) | Severity |
| OK/success | `--success` | `#16a34a` (`--green-600`) | Severity/positive |
| Focus ring | `--ring` | `#4d7c0f` (`--lime-700`) | `focus-visible` outline (visible on light) |

**Accent reserved for (never "all interactive elements"):**
1. Primary CTA button fill (`--accent` background, `--accent-foreground` text).
2. `focus-visible` ring on all focusable elements (`--ring`).
3. Active/current nav item indicator (underline or left-bar) in the header.
4. The brand wordmark accent glyph in the logo.
5. Inline text links (`--accent-text`, theme-aware shade).

Everything else uses neutral surfaces/borders. Severity colors (`--critical`/`--warning`/`--success`) are a SEPARATE semantic axis and are never substituted by the brand accent.

**Score-state mapping (coherence rule, DS-02):** `good → --success`, `needs_improvement → --warning`, `critical → --critical`. Same three tokens back both the severity scale (issues) and the score-state scale (categories) so they stay identical across the app.

| Token | Dark value | Light value | Usage |

## Base Layout Primitives

### Breakpoints (min-width, mobile-first)

| Token | Value | Target |
|-------|-------|--------|
| `--bp-sm` | 640px | Large phone / small tablet |
| `--bp-md` | 768px | Tablet |
| `--bp-lg` | 1024px | Desktop |
| `--bp-xl` | 1280px | Large desktop |

### Container

| Token | Value | Usage |
|-------|-------|-------|
| `--container-max` | 1200px | Default page content max-width, centered |
| `--container-narrow` | 720px | Forms, prose, verification/email screens |
| `--container-wide` | 1440px | Full report / graph surfaces (Phase 10) |

Inline padding (gutter): 16px (mobile) → 24px (≥640px) → 32px (≥1024px). Containers are centered with `margin-inline: auto` and never exceed viewport (no horizontal overflow — A11Y-01 foundation).

### Grid

12-column grid, `gap: var(--space-6)` (24px). Mobile collapses to a single column stack. Grid is a base primitive class; component-specific layouts compose on top in Phase 9.

### Header shell

- Height 64px, full-width, `position: sticky; top: 0; z-index: var(--z-sticky)`.
- Background `--surface`, `border-bottom: 1px solid var(--border)`.
- Contents (left → right): brand logo/wordmark (links to `/`), primary nav (Khand h4 role, 20px/500), spacer, theme toggle.
- Inline padding matches container gutter; content constrained to `--container-max`.

### Footer shell

- Background `--bg`, `border-top: 1px solid var(--border)`, vertical padding `var(--space-12)` (48px).
- Contents: brand wordmark, minimal links, copyright line (Body small, `--text-secondary`).
- Content constrained to `--container-max` with container gutter.

### Theme toggle (interaction contract)

- Icon-only button, ≥44×44px touch target, `--radius-full`.
- Toggles `data-theme` between `dark`/`light` via `next-themes`. Persists to `localStorage`; initial value from stored preference, else `prefers-color-scheme`.
- No FOUC: `suppressHydrationWarning` on `<html>`; theme resolved before paint by `next-themes`.
- Keyboard operable (Enter/Space), `focus-visible` ring, `aria-label` per state (see copy contract). Respects that motion for the icon transition follows `prefers-reduced-motion` (Phase 10 refines motion; foundation must not animate against the preference).
