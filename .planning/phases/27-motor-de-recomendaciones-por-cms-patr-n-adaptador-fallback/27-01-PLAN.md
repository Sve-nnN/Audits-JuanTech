<design_resolution>
**Firma de `CmsAdapter.lookup` — corrección sobre RESEARCH (CMSFIX-01, probe unclassified surfaced):**
El código de referencia en 27-RESEARCH.md usa `lookup(checkId, builder)` (2 argumentos). Esa firma NO puede satisfacer la decisión lockeada de CONTEXT ("Wix y Squarespace: mismo módulo técnico pero copy interno distinto por label"), porque el `registry` mapea TANTO `"Wix"` como `"Squarespace"` al mismo objeto adaptador y `lookup` no recibe qué label disparó la resolución. **Resolución de diseño:** la interfaz threadea el `CmsLabel`:

`lookup(checkId: string, label: CmsLabel, builder: AxisResult): string | null`

Los adaptadores WordPress/Shopify/Webflow ignoran `label` (single-label); `wixSquarespace.ts` ramifica sobre `label` para elegir el catálogo Wix vs Squarespace. El motor (Plan 02) pasa `cms.value` como el argumento `label`.
</design_resolution>
