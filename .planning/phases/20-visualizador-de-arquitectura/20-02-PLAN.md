<objective>
Extend `@auditor/report-model` so `buildReportModel` assembles an optional
`architecture` object from the link graph already persisted at `Audit.stats.graph`
(Phase 16) plus a single load of the audit's `Page` rows. Titles now come from the
REAL `Page.title` column added in Plan 20-01 (this plan depends on that column
existing — no phantom field). This is the pure-data foundation the SVG tree (Plan
20-03) renders. No HTML is re-parsed (ARCH-03); template per node comes from
`classifyTemplate` (ARCH-04).

Purpose: give the UI a serializable, degradation-safe architecture model without a
second graph computation and without touching the crawl pipeline.
Output: `ArchNode` / `ReportArchitecture` types + `ReportModel.architecture?` populated
in `build.ts`, exported from `index.ts`, covered by `build.test.ts`.
</objective>
